\#git notes



>1. git intit



It is a command used to Initialize a new git repository



example:

&#x09;git init





>2. git clone



This command is used to copy git repository to your computer 



example:

&#x09;git clone <repository url>



>3. git status



This command shows the current status of the working directory



example:

&#x09;git status



>4. git add



This command stages the changes for next commit



example:

&#x09;git add README.md



>5. git commit



This command creates a snapshot(kind of like a checkpoint) of staged changes



example:

&#x09;git commit -m "custom message"



>6. git log



This command shows the commit history



example:

&#x09;git log

&#x09;

&#x09;\_shorter version: git log --oneline



>7. git diff



This command shows the changes that have not been staged



example:

&#x09;git diff



>8. git push

This is the the command used to upload local commits to the remote repository



example:

&#x09;git push origin main



>9. git pull

This command downloads and integrates changes from the remote repository



example:

&#x09;git pull origin main



>10. git fetch



This command downloads information about remote changes without automatically integrating them



example:

&#x09;git fetch origin



>11. git branch



This command shows or manages branches



example:

&#x09;git branch



>12. git switch



This command is used to switch between branches



example:

&#x09;git switch main
