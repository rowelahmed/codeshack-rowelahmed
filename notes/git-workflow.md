> Git Workflow



A basic Git workflow helps developers safely manage changes and collaborate with others



> 1. To Check the current state



&#x20;  git status



> 2. To review the changes made 



&#x20;  git diff





> 3. To Initialize new repository



&#x20;  git init



> 4. To stage the changes for next commit



&#x20;  git add



> 5. To create a snapshot of staged changes



&#x20;  git commit



> 6. To upload local commits to the remote repository



&#x20;  git push











>> Why commits are useful



Commits create a history of project changes



A developer can inspect previous commits to understand

how a project evolved and identify when a change was introduced
