> Git Basics



> The "basic Git workflow"



A typical Git workflow is:



1\. Make changes to files

2\. Use git status to see what changed

3\. Use git diff to review changes

4\. Use git add to stage changes

5\. Use git commit to save a snapshot

6\. Use git push to send commits to GitHub



> Working Tree



The working tree contains the files being worked on



> Staging Area



The staging area contains the changes selected for the next commit



> Repository History



Commits are stored in Git history and provide snapshots

of the project development
